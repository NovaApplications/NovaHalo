## How to Add Releases

Instead of editing this file manually, please create releases directly on GitHub:

1. Go to [Releases](https://github.com/NovaApplications/NovaHalo/releases)
2. Click "Create a new release"
3. Enter version and release notes
4. Publish

Releases automatically appear on the website and in this changelog.
